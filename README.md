# 方舟关系图谱

《明日方舟》剧情人物关系的交互式图谱。

**在线访问：<https://gar1ton.github.io/web_Arknights_SocialNetworkAnalysis_Database/>**

把剧情台词当作一场漫长的群聊来读：谁和谁说过话，谁对谁友善、谁在谁面前强势，谁是连接不同圈子的关键人物。主线、活动和干员密录，每段剧情都有一张自己的关系图。

## 可以看到什么

**人际态度**
每组关系分两个方向来看：A 怎么看 B，B 又怎么看 A。态度用「友善—敌对」和「主导—顺从」两个维度描述，并归为友好、热情主动、主导、傲慢算计、冷淡、疏离回避、顺从、友善配合八类，画在一张环形坐标图上。

**关系网络**
谁的关系最多、谁说话最多、谁处在不同角色之间的桥梁位置；角色们自然形成了哪些圈子；整段剧情里的关系是亲近多还是疏远多。

**性格画像**
每个角色的大五人格（开放性、尽责性、外向性、宜人性、神经质），附一句性格简述和每项的评分理由。

## 怎么逛

1. 在首页选择一段剧情，或在目录里搜索剧情名、章节、角色名。
2. 点击角色，看 TA 的性格画像和人际态度；点击连线，看两人之间双向的态度。
3. 在「画布设置」里调整布局、连线颜色和角色名大小，喜欢的画面可以导出为图片。
4. 右上角「中 / EN」切换中英文界面。英文模式下，剧情标题、干员名和剧情角色名使用国际服官方译名（剧情角色名取自国际服剧情脚本中的说话人）；国际服尚未上线的剧情及其中的角色，以及人物性格简述与评分依据，暂时只有中文。

## 本地运行

```sh
npm ci
npm run dev    # http://localhost:4178
```

角色头像与剧情横幅由 `scripts/build_media.py` 生成（在 `build_data.py` 之后运行，需要 ffmpeg；参数见 `--help`）。英文界面用到的剧情英文标题与角色英文名在 `public/data/en.json`，由 `scripts/build_i18n.py` 生成（同样在 `build_data.py` 之后运行，需要国服与国际服的 `story_review_table.json`，以及可选的两服 `gamedata/story` 剧情脚本目录）。

### 二、数据解读须知

* **方向。** 关系 A → B 表示在某一段剧情中，模型推断出的 A 对 B 的印象。每组关系可能只有一个方向，也可能两个方向都有。
* **身份。** 无名角色按场景区分，不跨剧情合并：不同剧情里同名的人物是不同的人。
* **本站计算的指标。** 发言数、关系强度、社群、中介中心性和布局由本网站计算，仅供参考；用于正式发表的分析请自行重新计算。
* **缺失值。** 某项大五人格缺失表示「未评分」，不是零分。
