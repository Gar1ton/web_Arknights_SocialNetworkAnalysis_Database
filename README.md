# 方舟关系图谱

《明日方舟》剧情人物关系的交互式图谱。

**在线访问：<https://gar1ton.github.io/web_Arknights_SocialNetworkAnalysis_Database/>**

把剧情台词当作一场漫长的群聊来读：谁和谁说过话，谁对谁友善、谁在谁面前强势。主线、活动和干员密录，每段剧情都有一张自己的关系图，拖动时间轴可以看关系随剧情一步步形成。

## 可以看到什么

**首页**
关系网预览（最新加入的剧情）、这次更新新增的剧情，以及几屏数据：汇总数字和按类别的统计表；沿剧情年代每段剧情结束时有多少关系；关系落在友善度和支配度的哪里；八种关系类型各有多少；关系最多的角色和最鲜明的关系。后面是读图指南和项目介绍。

**剧情目录 / 角色目录**
剧情目录按剧情年代排列，最新加入的剧情排在最前，标着「新」或「续」。角色目录列出至少有一条关系的角色，可按关系数、出场剧情数或台词数排序。

**剧情图谱**
每段剧情一张关系网。画布下方是时间轴：按台词顺序从第 1 句到最后一句，上面的曲线是已经形成的关系数，拖动曲线或滑块、按播放、用键盘左右键逐个变化都可以移动位置；关系网只显示到那一句为止形成的关系，刚刚变化的连线会发光。右栏分四页：事件（按场景排列，跟着时间轴滚动，当前事件展开标题、参与者和经过，未发生的变暗）、角色（此刻的角色列表和网络概况）、图表（此刻的人际态度分布和八种类型）、设置（布局、连线、配色、只看具名角色）。点人物或连线看详情：关系详情里有两个方向的友善度、支配度随剧情变化的曲线；人物详情里的大五人格是累积到当前位置的画像。

**角色页**
一位角色的性格简述、大五人格及其随剧情年代的变化、在各段剧情里给出和收到的平均友善度、出场的剧情和关系对象；选一个关系对象，可以逐段剧情对比两人之间的双向态度，并直接打开那段剧情、选中这两人。

**人际态度**
每组关系分两个方向来看：A 怎么看 B，B 又怎么看 A。态度用「友善—敌对」和「主导—顺从」两个维度描述，并归为友好、热情主动、主导、傲慢算计、冷淡、疏离回避、顺从、友善配合八类。

## 怎么逛

1. 首页往下滚是最新加入的剧情和数据总览；点任何一段剧情、一根柱子或一行，都会打开对应的剧情或角色。
2. 在剧情图谱里拖动时间轴，或按「播放」（空格）、键盘左右键逐步看关系变化；点人物或连线看详情。地址栏会记下选中的人物或关系（如 `#graph/main-08/145`、`#graph/main-08/145-301`），可以直接分享。
3. 剧情图谱「设置」里的「只看具名角色」默认打开，会隐藏「士兵」这类只在单段剧情出现的泛称角色；「中 / EN」切换中英文界面。英文模式下，剧情标题、干员名和剧情角色名优先使用国际服官方译名；没有译名的仍显示中文。事件标题与经过、人物性格简述暂时只有中文。

## 本地运行

```sh
npm ci
npm run dev    # http://localhost:4178
npm test
```

`public/data` 由 `scripts/build_temporal.py` 从一次全剧情运行生成（参数见 `--help`）：运行的数据先在 TSRA 仓库里用 `sna/temporal/arknights_view.py RUN_ID --json work/view_data.json` 导出（含引作证据的原文，只放在被 git 忽略的 `work/` 里），脚本再取出可以公开的部分，沿用上一版的剧情编号、英文名、头像和横幅（`--old` 指向上一版 `public/data`，可从 git 历史取出），并检查没有任何证据原文进入输出。

`scripts/build_media.py`（头像与横幅）和 `scripts/build_i18n.py`（英文名）读取的是上一版数据格式，这一版沿用它们之前生成的 `public/media/` 和 `en.json`；新加入的角色暂时没有头像和英文名。

### 二、数据解读须知

* **方向。** 关系 A → B 表示在某一段剧情中，模型推断出的 A 对 B 的印象。每组关系可能只有一个方向，也可能两个方向都有。
* **时间。** 时间轴上的位置按故事内的台词顺序计。关系在每个故事里从零开始，随剧情形成和变化；不同故事里的同一对角色各算各的。
* **身份。** 无名角色按场景区分，不跨剧情合并：不同剧情里同名的人物是不同的人。
* **本站计算的指标。** 发言数、各图的汇总统计和布局由本网站计算，仅供参考；用于正式发表的分析请自行重新计算。
* **缺失值。** 某项大五人格缺失表示「未评分」，不是零分。
